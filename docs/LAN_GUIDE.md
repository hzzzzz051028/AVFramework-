# 🌐 屏幕共享系统 - 局域网使用指南

## 📋 快速开始

### 步骤 1: 在主机上启动服务器

**主机** = 运行服务器的电脑（屏幕共享源）

```powershell
# 打开 PowerShell 或 CMD，进入项目目录
cd C:\Users\1000003244\Desktop\video_test

# 运行启动脚本
scripts\run-screenshare.bat
```

**服务器窗口会显示：**
```
========================================
   Screen Share Signaling Server v2.0
========================================

[LAN Access Information]
  Local IP:        192.168.1.100
  HTTP Server:     http://192.168.1.100:8080
  WebSocket:       ws://192.168.1.100:8081
```

⚠️ **记下你的 IP 地址**（例如：`192.168.1.100`）

---

### 步骤 2: 在主机上开始共享屏幕

浏览器会自动打开，或者手动打开：
```
frontend\screenshare.html
```

1. 确保选中 **"📤 共享屏幕"** 模式
2. 点击 **"🎬 开始共享"** 按钮
3. 选择要共享的屏幕/窗口
4. **复制会话 ID**（例如：`sess_abc123`）

---

### 步骤 3: 在其他设备上观看

**观看设备** = 局域网内的其他电脑

#### 方法 A: 使用相同的 HTML 文件

1. 将 `frontend\screenshare.html` 复制到观看设备
2. 用浏览器打开
3. 切换到 **"📥 观看屏幕"** 模式

#### 方法 B: 通过网络共享访问

1. 确保观看设备可以访问主机的文件共享
2. 打开网络路径：`\\192.168.1.100\video_test\frontend\screenshare.html`

#### 方法 C: 使用本地 Web 服务器（可选）

在主机上运行：
```powershell
# 进入 frontend 目录
cd frontend

# 启动简单 HTTP 服务器（Python）
python -m http.server 8000

# 或使用 Node.js
npx http-server -p 8000
```

然后在观看设备浏览器访问：
```
http://192.168.1.100:8000/screenshare.html
```

---

### 步骤 4: 配置观看设备

在观看设备的浏览器中：

1. 找到右侧 **"⚙️ 服务器配置"** 面板
2. 在 **"WebSocket 服务器地址"** 输入框中输入：
   ```
   ws://192.168.1.100:8081
   ```
   （替换为你的实际 IP）

3. 点击 **"🔄 测试连接"** 按钮
4. 状态指示灯变绿说明连接成功

![配置面板](config_panel_example.png)

---

### 步骤 5: 连接观看

1. 在 **"输入会话 ID"** 框中输入：`sess_abc123`
2. 点击 **"🔗 连接"** 按钮
3. 等待连接建立（2-5秒）
4. 开始观看远程屏幕！

## 🔧 详细配置

### 主机配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| HTTP 端口 | 8080 | 健康检查端口 |
| WebSocket 端口 | 8081 | 信令服务端口 |
| 心跳间隔 | 30秒 | 心跳检测间隔 |
| 客户端超时 | 60秒 | 无响应超时时间 |

### 防火墙配置

**如果其他设备无法连接，需要配置防火墙：**

#### Windows 防火墙

```powershell
# 以管理员身份运行 PowerShell

# 允许 HTTP 端口
New-NetFirewallRule -DisplayName "Screen Share HTTP" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow

# 允许 WebSocket 端口
New-NetFirewallRule -DisplayName "Screen Share WebSocket" -Direction Inbound -Protocol TCP -LocalPort 8081 -Action Allow
```

#### 图形界面配置

1. 打开 **Windows Defender 防火墙**
2. 点击 **"高级设置"**
3. 选择 **"入站规则"** → **"新建规则"**
4. 规则类型：**端口**
5. 协议：**TCP**，端口：**8080, 8081**
6. 操作：**允许连接**
7. 重复一次为 UDP（如果需要）

**健康检查：**
```
http://192.168.1.100:8080/health
```

返回：
```json
{
  "status": "ok",
  "timestamp": "2024-04-23T10:30:00.000Z",
  "sessions": 1,
  "clients": 2,
  "uptime": 123.456
}
```

**服务器信息：**
```
http://192.168.1.100:8080/info
```

返回：
```json
{
  "server": "Screen Share Signaling Server",
  "version": "2.0.0",
  "ws_port": 8081,
  "http_port": 8080,
  "local_ip": "192.168.1.100",
  "sessions": [...]
}
```

### 日志查看

**前端日志面板：**
- 实时显示所有连接活动
- 分级显示：INFO / SUCCESS / WARN / ERROR
- 点击 **"清空"** 按钮清除日志

**服务器日志：**
- 在服务器窗口实时查看
- 格式：`[时间] [级别] [分类] 消息`

## 🔄 断线重连

### 自动重连

系统会自动处理短暂的网络中断：

| 断开时长 | 行为 |
|----------|------|
| < 2 秒 | 立即重连 |
| 2-10 秒 | 指数退避重连 |
| > 10 秒 | 最多尝试 5 次 |

### 手动重连

如果自动重连失败：

**观看端：**
- 点击重连横幅中的 **"立即重连"** 按钮

**共享端：**
- 点击 **"🛑 停止共享"** 后重新开始

## ❓ 常见问题

### Q1: 观看设备无法连接到服务器

**检查清单：**
- [ ] 两台设备在同一局域网
- [ ] 防火墙已允许端口 8080/8081
- [ ] IP 地址正确（使用 `ipconfig` 确认）
- [ ] 服务器正在运行
- [ ] 使用测试连接功能验证

### Q2: 连接成功但看不到画面

**解决方法：**
1. 检查会话 ID 是否正确
2. 查看日志面板的错误信息
3. 确认共享端已开始共享
4. 刷新页面重试

### Q3: 画面卡顿或延迟高

**优化建议：**
- 降低共享分辨率
- 共享单个窗口而非整个屏幕
- 关闭不必要的网络应用
- 使用有线网络而非 Wi-Fi

### Q4: 如何获取本机 IP 地址

**Windows:**
```powershell
ipconfig
```
找到 "IPv4 地址"（例如：`192.168.1.100`）

**查看服务器窗口：**
启动服务器时会自动显示 IP 地址

## 🔒 安全提示

1. **仅在可信网络使用** - 仅在局域网内使用，不要暴露到公网
2. **会话 ID 保护** - 不要将会话 ID 泄露给无关人员
3. **及时停止共享** - 使用完毕后立即停止共享
4. **防火墙配置** - 仅允许可信 IP 访问（可选）

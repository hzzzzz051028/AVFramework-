# Skills 目录

此目录包含项目的开发经验和上下文知识，用于在不同开发环境间快速迁移。

## 可用 Skills

| Skill | 描述 | 状态 |
|-------|------|------|
| [webrtc-screen-sharing](webrtc-screen-sharing.md) | WebRTC 无线投屏系统开发经验 | ✅ 当前 |

## 使用方法

### 1. 在对话中加载
```
请根据 skills/webrtc-screen-sharing.md 的内容了解项目背景
```

### 2. 更新进展
直接编辑对应的 skill 文件，在"更新日志"部分添加新的条目。

### 3. 添加新 Skill
创建新的 `.md` 文件，包含以下 frontmatter：
```yaml
---
name: skill-name
description: 简短描述
---
```

## 目的

- 🔁 **环境迁移**: 快速在新机器上恢复上下文
- 📝 **知识积累**: 记录开发中遇到的问题和解决方案
- 🚀 **协作**: 与团队成员共享经验
